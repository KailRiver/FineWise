# FineWise

**FineWise** — это простое консольное приложение для управления личными финансами, написанное на Java. Оно позволяет пользователям регистрироваться, входить в систему, добавлять доходы и расходы, устанавливать бюджеты по категориям, переводить деньги другим пользователям и просматривать финансовую статистику.

---

## Основные функции

- **Регистрация и вход**: Пользователи могут зарегистрироваться с уникальным логином и паролем, а затем войти в систему.
- **Управление финансами**:
    - Добавление доходов и расходов.
    - Установка бюджета для категорий.
    - Перевод денег другим пользователям.
- **Статистика**: Просмотр текущего баланса, общего дохода, расходов и бюджета по категориям.
- **Сохранение данных**: Данные пользователей сохраняются в файлы JSON для последующего использования.
